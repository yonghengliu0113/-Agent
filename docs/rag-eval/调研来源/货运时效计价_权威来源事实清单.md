## 一、零担（LTL）与整车（FTL）的官方界定差异

### 1.1 法规层面：中国现行道路货运法规**没有**按重量/体积划分零担与整车

【法规强制】《道路货物运输及站场管理规定》（交通运输部令2026年第5号，2026年2月6日公布，**自2026年3月20日起施行**，系第八次修正）

- 第二条将「道路货物运输站（场）」定义为"以场地设施为依托，为社会提供有偿服务的具有仓储、保管、配载、信息服务、装卸、理货等功能的综合货运站（场）、**零担货运站**、集装箱中转站、物流中心等经营场所"——即法规只出现"零担货运站"这一设施概念，**未规定零担/整车的重量或体积门槛**。
- 全文未见 30kg / 500kg / 3吨 等划分标准。
- 来源：贵州省交通运输综合行政执法监督局转载全文 http://jtzhzf.guizhou.gov.cn/zwgk/fdzdgknr/zcwj/flfg/202604/t20260408_89972880.html （发布时间 2026-04-08，成文日期 2026-02-06）；邯郸市交通运输局 http://jtj.hd.gov.cn/pub/mobile/zwgk/zcfg/79062.htm （时间 2026-02-27）

> **结论：零担/整车的重量门槛不是法规强制概念，而是承运商的商业产品分段。** 下列均为【承运商商业规则】。

## 二、计费重量（chargeable weight）计算规则与体积重量换算系数

> **重要区分：以下每家的系数逐字来自各自官方页面，不可跨来源混用。**

### 2.1 顺丰速运（官方，系数最完整）

【承运商商业规则】顺丰速运官网「运费时效查询」页 https://www.sf-express.com/chn/sc/price-query （页面未标注日期）

原文明示的基本规则：

- "**计费重量指包裹的总重量，包括货物本身、包装材料及必要的辅助物品（如冰袋、泡沫箱等）**"
- "**托寄物的计费重量取体积重量与实际重量两者之间的较大值**，若为子母件，则将每件的计费重量进行汇总后计算总运费"
- "体积重量的计算方法为：体积重量 = 长(cm) × 宽(cm) × 高(cm) ÷ 系数"

各产品系数（逐字）：

| 产品 | 体积重量换算 |
|---|---|
| **顺丰特快** | 中国内地大部分流向互寄 **÷6000**；黑/吉/辽/内蒙部分省（自治区）内及互寄流向 **÷12000** |
| **顺丰标快** | 实际重量 **30kg以下 ÷12000**（部分优惠顺丰标快产品 ÷6000）；实际重量 **30kg及以上 ÷6000**；西藏昌都市与西藏自治区内其他城市互寄、西藏昌都市与海南三沙市互寄 **÷6000** |
| **顺丰卡航 / 冷运标快** | **÷6000** |
| **冷运大件** | **÷3000** |
| **港澳台（服务）** | **÷6000** |
| **国际快递（服务）** | **÷5000** |
| **顺丰半日达** | **÷6000** |

计费重量进位规则（逐字）：
- 中国内地互寄：10kg以下，续重以 **0.1kg** 为计重单位；10-100kg，续重以 **0.5kg** 为计重单位；100kg及以上，**四舍五入取整数**。
- 港澳本地：续重以 **0.5kg** 为单位，不足0.5kg按0.5kg计。
- 中国内地始发至港澳台：100kg以下续重 **0.5kg**（不足按0.5kg）；100kg及以上以 **1kg** 为单位，尾数大于零向上进位至下一个1kg。
- 中国内地始发至海外：20kg以下续重 **0.5kg**；20kg及以上以 **1kg** 为单位，尾数大于零向上进位至下一个1kg。
- 运费计算结果按**四舍五入取整数值**。

## 三、抛比 / 轻抛货的定义与计算示例

### 3.1 定义与公式（有公开来源的部分）

- 【承运商商业规则 · 顺丰】定义："托寄物的计费重量取体积重量与实际重量两者之间的较大值"（同时覆盖重货与轻抛货两种情形）。来源：https://www.sf-express.com/chn/sc/price-query
- 【第三方 · 壹米滴答】定义："体积重量=长(cm)×宽(cm)×高(cm)÷抛重系数"，全部公斤段抛重系数6000。来源：https://kbkfdocs.kuaidihelp.com/docs/weikuaidi/weikuaidi-1ft7sfe0qd9tq
- 【第三方 · 政府采购文件中的抛货注解】"重量 > 立方为重货，计算按照重量计算；重量 < 立方为抛货，**抛货比例1立方 = 240KG** 计算"。来源：广西壮族自治区体育局政府采购文件 http://tyj.gxzf.gov.cn/gkxxgl/zfcg_83527/P020240229557236416350.pdf （该 PDF 由搜索引擎返回片段，未能抓取正文核验；且 1m³=240kg 系该项目采购文件口径，**不是承运商通用规则**）

### 3.2 计算示例

- **未找到权威来源**：各承运商官网均未给出抛货计算的数值示例。顺丰页面只给公式与系数；德邦、安能、跨越页面上未读到示例。
- 可自行按已核验公式推算（示例本身为推导，非来源原文），例如按顺丰标快 ≥30kg 口径：一件 100cm×80cm×60cm、实重 40kg 的货物，体积重 = 100×80×60÷6000 = 80kg > 40kg，故**计费重量取 80kg**。该示例为按官方公式的推演，**来源中并无此例**。

### 8.3 GB 1589-2016 的具体限值（行业媒体转述，非标准正文）

【第三方/非权威 · 行业媒体转述】运输人网《2016版GB1589实施 涉及六项重大变革》 https://www.yunshuren.com/article-5537.html （2016-08-01）

原文逐字（该文称依据"中国国家标准化管理委员会 2016年第12号中国国家标准公告"）：

1. **外廓尺寸**："车宽由原来的 **2.5米** 变化为 **2.55米（冷藏车2.6米）**，以满足装载两排托盘的宽度需求。"
2. **挂车长度**："仓栅式、栏板式、平板式、自卸式半挂车长度不变，其它半挂车长度限值 **13.75米**，运送 **45英尺集装箱的半挂车长度最大限值为 13.95米**，封闭式厢式半挂车从 **14.6米** 减少到了目前的 **13.75米**。"
3. **中置轴车型**："中置轴挂车长度限值 **12米**，由货车和牵引杆挂车或中置轴挂车的组合属于货车列车，货车列车长度限值 **20米**（中置轴车辆运输列车限长 **22米**）。"
4. **铰接列车**："铰接列车长度限值为 **17.1米**，比16.5米的标准增加了0.6米（封闭式厢式半挂车组成的铰接列车长度限值由 **18.1米** 减少到了 **17.1米**），**长头铰接列车（长头牵引车+半挂车）长度限值为 18.1米**。"
5. **空气悬架政策**："三轴客车、货车、半挂牵引车以及 8X4 载货车，当中驱动轴为每轴每侧双轮胎且装备空气悬架时，**总重限值增加1吨**。此外**四轴汽车列车，加装空气悬架后，最大允许总质量限值增加1吨为 37吨**。"
6. **轴重**："**6轴车限重49吨**，按照GB1589规定计算，**双导6X2、后提升6X2牵引车组成的6轴列车总重限值为 46吨**。"

> ⚠️ 以上为**行业媒体转述**，非标准正文。GB 1589-2016 标准正文未能抓取（见 8.5）。

### 8.4 与 GB 1589 联动的执法口径（法规强制，可交叉验证上述数值）

【法规强制】《超限运输车辆行驶公路管理规定》（交通运输部令2016年第62号）第三条（来源同上 7.1）逐字：

本规定所称超限运输车辆，是指有下列情形之一的货物运输车辆：
- （一）车货总高度从地面算起 **超过4米**；
- （二）车货总宽度 **超过2.55米**；
- （三）车货总长度 **超过18.1米**；
- （四）二轴货车，其车货总质量 **超过18000千克**；
- （五）三轴货车，其车货总质量 **超过25000千克**；三轴汽车列车，其车货总质量 **超过27000千克**；
- （六）四轴货车，其车货总质量 **超过31000千克**；四轴汽车列车，其车货总质量 **超过36000千克**；
- （七）五轴汽车列车，其车货总质量 **超过43000千克**；
- （八）六轴及六轴以上汽车列车，其车货总质量 **超过49000千克**，其中**牵引车驱动轴为单轴的，其车货总质量超过46000千克**。

认定补充要求（逐字）：
- （一）二轴组按照二个轴计算，三轴组按照三个轴计算；
- （二）除驱动轴外，二轴组、三轴组以及半挂车和全挂车的车轴**每侧轮胎按照双轮胎计算，若每轴每侧轮胎为单轮胎，限定标准减少3000千克**，但安装符合国家有关标准的加宽轮胎的除外；
- （三）**车辆最大允许总质量不应超过各车轴最大允许轴荷之和**；
- （四）拖拉机、农用车、低速货车，以**行驶证核定的总质量**为限定标准；
- （五）**符合《汽车、挂车及汽车列车外廓尺寸、轴荷及质量限值》（GB1589）规定的冷藏车、汽车列车、安装空气悬架的车辆，以及专用作业车，不认定为超限运输车辆。**

其他相关限值（逐字）：
- 第十条第二款：车货总高度 **超过4.5米**，或总宽度 **超过3.75米**，或总长度 **超过28米**，或总质量 **超过100000千克** 的，还应提交载货时车货总体外廓尺寸信息的**轮廓图和护送方案**。
- 第十七条：**采用普通平板车运输，车辆单轴的平均轴荷超过10000千克或者最大轴荷超过13000千克的**，不予行政许可；**采用多轴多轮液压平板车运输，车辆每轴线（一线两轴8轮胎）的平均轴荷超过18000千克或者最大轴荷超过20000千克的**，不予行政许可。
